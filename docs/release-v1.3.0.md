# mbfTwain v1.3.0

本次更新把大批量图片导入、预览和送图流程统一到同一窗口，并改善慢网络场景下的响应与恢复体验。

## 新增与优化

- **统一进度界面**：送图期间在原窗口显示准备、传输、暂停和恢复状态，避免额外对话框遮挡队列。
- **分离图片读取任务**：缩略图、清晰预览和送图使用独立的有界读取调度，慢缩略图不会阻塞显式预览或送图。
- **批量恢复与分页**：恢复记忆队列时按页加载缩略图，启动中的恢复任务可被首次主机会话复用，避免重复清空和重复加载。
- **异常处理更稳定**：图片读取失败、取消和中止后保留可继续的队列状态，按钮与加载状态在各路径正确恢复。
- **隔离 UI 回归测试**：新增隐藏独立 Windows 桌面运行的界面冒烟脚本，覆盖布局、交互和调度检查，不干扰当前桌面。

## 验证

- Win32、x64 TWAIN Data Source 与 .NET UI Release 构建通过。
- TWAIN 原生入口、IPC、分页传输、取消/继续和旧版 DSM 冒烟测试通过。
- 隔离 UI 冒烟测试及交互专项测试通过。
