# mbfTwain v1.2.0

本次更新改善数百张图片的选择、恢复与传输体验，并为慢网络和异常图片提供可取消、可继续的处理流程。

## 新增与优化

- **大批量图片分页**：每页显示 12 张，仅加载当前页缩略图；扫描按批获取路径、逐张准备图片，避免一次读入整批图像。
- **后台加载与超时处理**：恢复队列、缩略图和预览不阻塞界面；单张网络图片读取最多等待 10 秒，超时后提示处理。
- **取消、继续与中止**：导入和送图支持取消后继续，保留处理进度；中止送图后保留尚未完成的图片队列。
- **异常图片处理**：图片缺失、不可访问或损坏时，提示具体图片并提供重试、跳过继续、更换图片和中止选项；结束后汇总跳过项，保留原记忆记录。
- **加载状态更清晰**：导入与预览增加 Loading、等待遮罩和取消入口；统一按钮禁用、悬停与焦点状态；更新检查和下载可取消。
- **TWAIN 兼容性**：保留原生 DIB、缓冲内存传输和传输张数限制，并包含旧版 TWAIN 管理器等待取图问题的修复。

## 验证

- Win32、x64 构建及现有 TWAIN 冒烟测试通过。
- 两种架构各 500 张原生图像传输、跨批取图和取消后继续验证通过。
- 缓冲内存传输、传输张数限制，以及缺图、损坏图片、更换、跳过末张、全部跳过和 10 秒超时处理验证通过。
- 加载遮罩、按钮状态及取消后恢复验证通过。

## 安装

- `mbfTwain-Setup-v1.2.0.exe`
- `mbfTwain-Setup-v1.2.0.exe.sha256`

安装包同时包含 Win32 与 x64 TWAIN 源及配置界面，需要管理员权限。运行配置界面需要安装 .NET 10 Desktop Runtime。
